# Session Handoff — Instructions

This file is a template/instruction set for producing a session handoff, used when switching Claude Code sessions mid-task (e.g. to get a fresh token quota). When asked to "update status.md" or "save the handoff," follow the prompt below and overwrite the content of this file with the actual report it describes — a new session with zero prior context should be able to read only this file and know exactly where the project stands and what to do next.

---

Please create a file called status dot M D in the root of this repository, and make it comprehensive enough that a completely new session with no prior context could read only this file and immediately understand where the project stands and what to do next. Structure it with these sections. First, current state — a plain description of what is currently working end to end, verified and functioning, not just written. Second, in progress — exactly what you were working on right when this file was created, including the specific file or files involved, the exact change or feature being implemented, and how far along it is. Third, known issues — any bugs, errors, or broken behavior you're aware of right now, including error messages if applicable and where in the code they originate. Fourth, next step — the single next action that should be taken, described specifically enough that no guessing is needed, plus any secondary steps after that in order. Fifth, recent decisions — any choices made recently about how something should work, especially if there was back and forth or alternatives considered, so they are not re-litigated. Sixth, environment and access notes — anything about credentials, API keys, console projects, or external services that a new session would need to know to continue working, without including the actual secret values themselves. Please be specific rather than general throughout. Name actual file names, actual function or variable names, and actual error text rather than describing things vaguely. Do not summarize down to save space. This file will be the only context a fresh Claude session has, so err on the side of including detail that seems obvious to you right now but would not be obvious without today's context.
